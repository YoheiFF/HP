About

自己紹介

技術よりも、まず「何を解決したいか」を一緒に整理することを大切にしています。

フリーランスエンジニアとして、主にC#/.NETを用いた業務システムの開発・設計に携わっています。 要件定義や基本設計といった上流工程から参画し、関係者との認識合わせを丁寧に進めながら開発を進めることを得意としています。

「技術的にできるか」より先に「何のために作るか」を整理する。 そのためのコミュニケーションを惜しまないことが、品質とスピードの両立につながると考えています。 エンジニアとクライアントの間に立ち、橋渡しができる存在を目指しています。

主な活動

C#/.NETを用いた業務システムの設計・開発。フリーランスとして複数プロジェクトに参画。

大切にしていること

上流からの関与、丁寧なヒアリング、認識のズレを生まないコミュニケーション。

強み

技術とビジネス要件をつなぐ視点。要件定義から実装まで一貫して担える柔軟性。

Possible / Skills

今できること

技術スキルと上流の視点を組み合わせ、要件整理から納品まで一気通貫で対応できます。

要件定義・仕様整理

ヒアリングをもとに業務フローを整理し、仕様書・画面設計書などの上流ドキュメントを作成します。

C# / .NET 開発

業務システムを中心に、設計から実装・テストまで対応。保守性を意識したコード設計を心がけています。

ステークホルダー対応

クライアントや現場担当者との認識合わせを丁寧に行い、手戻りの少ない進め方を実現します。

プロジェクト推進支援

小規模チームでの進行管理や、技術・ビジネス間の橋渡し・折衝サポートにも対応できます。

「何を作るか」がまだ固まっていない段階からでも、一緒に整理しながら進めることができます。

Message

開発に向き合う姿勢

技術は目的ではなく、課題を解決するための手段だと考えています。 だからこそ、コードを書く前に「何のために作るのか」を丁寧に確認することを大切にしています。

認識のズレは早いほど安く直せる。そのための対話を惜しまず、 クライアントが安心して任せられるエンジニアであり続けたいと思っています。
